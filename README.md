### 👨‍💻 Sobre Mim & Trajetória Profissional

- 💼 **Atuação Corporativa Atual:** Desenvolvedor / Estagiário de T.I. na **Nova Smar S/A**, onde desenvolvi e mantenho em produção um **Dashboard Financeiro e de Automação ERP** (PHP, Oracle PL/SQL, TOTVS Protheus, MySQL), além de triggers/procedures para conciliação contábil e relatórios de estoque que viabilizaram a conclusão do inventário corporativo em tempo recorde em 2025.
- 🎓 **Formação Acadêmica:** Bacharelado em **Ciência de Dados** pela **UNIVESP** (*Universidade Virtual do Estado de São Paulo*).
- ⚡ **Engenharia de Software & Versatilidade Técnica:**
  - **Backend & Microsserviços:** Java 21 LTS, Spring Boot 3, Spring Security, arquitetura orientada a eventos com RabbitMQ, Redis Sliding Window Cache e Docker.
  - **Frontend & Web Moderna:** React 19, Next.js 16 (App Router), TypeScript, Tailwind CSS v4, Zustand, Zod e suíte de testes com Vitest.
  - **Ciência de Dados & ML:** Python (Scikit-learn, LightGBM, SHAP Explainable AI, Pandas), Web Scraping automatizado e dashboards em Streamlit.
  - **Mobile Nativo & IA:** Kotlin 2.0 (Jetpack Compose, Clean Architecture, Offline-First, P2P), Google MediaPipe Hands (Visão Computacional na GPU), Tone.js e integração de LLMs (Google Gemini API / FastAPI).
- 📈 **Bagagem Empreendedora & Visão de Negócio:** 5 anos de experiência liderando operação própria no e-commerce (**Mercadolíder** em menos de 1 ano), gerenciando precificação, análise de dados de vendas e relacionamento com clientes. Vivência prática que orienta cada linha de código para solucionar dores reais de negócio.
- 🌍 **Idiomas:** Português (Nativo) · Inglês (Intermediário Técnico B2) · Alemão (Básico A1).
